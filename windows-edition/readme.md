here is the user manual for Turtle Launcher:

1.) To add games to the launcher go to the "Library" page and press add game, make sure that the game you choose is a .exe file.
2.) To delete a game press the "Edit" button underneath that game and press delete.
3.) To rename a game go to the "Library" page then press the "Edit" button underneath that game and type in the new name and press save.
4.) To change the icon of a game go to the "Library" page then press the "Edit" button underneath that game and press change icon make sure that the icon is an image file and then press save.
5.) To change the accent color of the launcher go to the "Settings" page and pick one of the accent colors then press the "Restart" button.
