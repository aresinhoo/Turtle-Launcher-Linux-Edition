# Turtle-Launcher
Turtle Launcher (kind of a fake steam)
The .exe file is in the "executable" folder.

## HOW TO INSTALL
1. Go to the "releases" tab on the right
2. Pick the latest/any version of Turtle Launcher
3. Download the folder
4. Open the terminal
5. cd to the folder where Turtle Launcher downloaded
6. Run chmod +x TurtleLauncher-linux
7. Run ./TurtleLauncher-linux
8. EXTRA: Some file managers let users to make files executable so if you can do that to make it easier to launch
9. Enjoy!
